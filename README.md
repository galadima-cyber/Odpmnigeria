# ODPM Nigeria — PHP + MySQL Web App

This refactors the existing TailwindCSS static site into a dynamic PHP 8 + MySQL application with an admin dashboard, session auth, CSRF protection, secure uploads, and prepared statements.

## Tech Stack
- PHP 8+
- MySQL 8+
- TailwindCSS (CDN)
- Session-based auth with `password_hash()` / `password_verify()`

## Folder Structure
```
ODPM/
├─ public/                # Frontend pages
│  ├─ index.php           # Home (news highlights)
│  ├─ about.php           # Dynamic About page (from `pages` table)

│  ├─ news-single.php     # News article
│  └─ gallery.php         # Gallery
│  └─ reports.php         # Public report submission (with file upload)

│  ├─ dashboard.php       # Overview

│  ├─ manage-news.php     # CRUD news (image upload)
│  ├─ manage-gallery.php  # Upload/Delete images
│  ├─ manage-reports.php  # View/Filter/Respond/Status updates

├─ includes/              # Shared code
│  ├─ db.php              # PDO connection
│  ├─ functions.php       # Helpers (escape, csrf, uploads, slugify)
│  ├─ auth.php            # Auth helpers
│  ├─ header.php          # Site header/nav

├─ images/                # Existing static images

```

## Setup (Local on AppServ)
1. Copy this folder under your web root (already at `c:\AppServ\www\ODPM`).
2. Create database and import schema:
   - Create database: `odpm_db`
   - Import `db.sql` using phpMyAdmin or CLI:
     - CLI example: `mysql -u root -p odpm_db < c:\\AppServ\\www\\ODPM\\db.sql`
3. Configure DB credentials in `config.php` if needed.
4. Create an admin user (generate a bcrypt hash):
   - Run this quick PHP snippet once (e.g. `hash.php`) to get a hash for your password:
     ```php
     <?php echo password_hash('ChangeMe123!', PASSWORD_DEFAULT), PHP_EOL; ?>
     ```
   - Insert the user (replace HASH below):
     ```sql
     INSERT INTO users (email, name, password_hash, role)
     VALUES ('admin@example.com','Admin','HASH','admin');
     ```
5. Visit the site:
   - Frontend: http://localhost/ODPM/public/index.php
   - Admin: http://localhost/ODPM/admin/index.php

## Usage Notes
- Pages management (`admin/manage-pages.php`) powers `public/about.php` and can also host `founder` / `executives` content. Create pages with slugs `about`, `founder`, `executives`.
- News images are uploaded to `/uploads/` with sanitized filenames. Slug is autogenerated if left blank.
- Gallery uploads and deletions are handled in `admin/manage-gallery.php`.
- Reports are submitted by the public (`public/reports.php`) and triaged in `admin/manage-reports.php` with status and response fields.

## Security
- All DB interactions use prepared statements via PDO.
- Passwords hashed with `password_hash()` and verified with `password_verify()`.
- CSRF tokens included in all mutating forms.
- Outputs escaped via `e()` helper.
- Uploads:
  - Allowed MIME types and size are enforced from `config.php`.
  - Filenames sanitized and randomized to avoid collisions.

## Customization
- Update Tailwind color palette in `includes/header.php` (inline `tailwind.config`).
- Update nav links/branding in `includes/header.php` and `includes/footer.php`.
- Adjust upload limits and allowed types in `config.php`.

## Migrating Existing Static Content
- Use `admin/manage-pages.php` to paste in your current text for About, Founder, and Executives.
- Use `admin/manage-news.php` to create news items and upload cover images.
- Use `admin/manage-gallery.php` to upload images previously referenced in `gallery.txt`.
